Accounts, organizations, votes, flags, comments

taurctl talks only to the HTTP API. The token file is mode 0600 under --config-dir (default ~/.config/taurctl). Point tests at another directory.

Account

taurctl --server https://packages.taur.weirdbrains.com --config-dir /tmp/taurctl register alice alice@example.com
# read the token from the outbox when SMTP is unset, then:
taurctl --config-dir /tmp/taurctl verify TOKEN
taurctl --config-dir /tmp/taurctl login alice
taurctl --config-dir /tmp/taurctl whoami

Unverified users can search and clone. They cannot push or run other git-serve commands. taur admin NAME grants site admin. taur admin NAME --revoke removes it. TAUR_ADMINS only grants.

Organizations

taurctl org create brains
taurctl org add-member brains bob --role contributor
taurctl pkg transfer hello-taur --org brains

Roles are owner, admin, and contributor. Owners are the only ones who can delete the org or change the owner role.

Votes, flags, comments, requests

taurctl pkg vote hello-taur
taurctl pkg flag hello-taur --comment "upstream moved"
taurctl pkg comment hello-taur --message "note"
taurctl request file hello-taur --kind orphan --comment "please adopt"

An orphan request for a package flagged out-of-date for 180 days is accepted when it is filed. Adoption requests are not. A site admin accepts or rejects the queue with taurctl request accept ID.
