# Metadata dumps

Generated on request, gzip (`application/gzip`):

- `/packages.gz` — package names, one per line
- `/pkgbase.gz` — package base names, one per line
- `/packages-meta-v1.json.gz` — JSON array of search-shaped package objects
- `/packages-meta-ext-v1.json.gz` — JSON array of info-shaped objects (adds Depends,
  License, Keywords, CoMaintainers etc.), like aurweb's extended dump
