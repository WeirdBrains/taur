---
title: Moderator guide
summary: Reject a package or an ordinary account, and what you cannot do.
audience: moderator
order: 80
---

A moderator can reject a package base or an ordinary account. Open the package or the user page, write a reason, and confirm.

A rejected package disappears from search and cannot be cloned or pushed. The git repository stays. A rejected account cannot sign in, and its sessions end. The account row stays.

You cannot:

- grant or remove moderator, admin, or owner
- accept, reverse, or revoke an audit decision
- accept package requests
- see email addresses
- suspend a site admin, a site owner, or another moderator
- manage registries, operator keys, or mirrors

Those stay with a site admin or a site owner. Reversing a rejection is an admin action on **Audit**.
