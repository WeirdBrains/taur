---
title: Package requests
summary: Ask for an orphan, a deletion, a merge, or an adoption.
audience: user
order: 60
---

On a package page, file a request: orphan, deletion, merge, or adoption. A merge names the package base it should become. Say why.

**Requests** lists what is still open. You can withdraw your own. A site admin accepts or rejects it. Accepting an orphan, deletion, or merge carries it out. Accepting an adoption makes you the maintainer.

A rejected request stays closed. File a new one if the situation changes. A site admin does not turn a rejected request into an acceptance.
