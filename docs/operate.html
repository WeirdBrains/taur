Configure, services, backups, upgrades

Flags override environment variables. The SMTP URL is never logged. Copy .env.example and source it, or use it as a systemd EnvironmentFile=.

Settings you will set

VariableRole
TAUR_HOMEDatabase, repos/, outbox, host key.
TAUR_BINDListen address. Default 127.0.0.1:8080. HTTP when TLS is off, HTTPS when it is acme.
TAUR_TLSoff (default, plaintext or a proxy) or acme (automatic HTTPS).
TAUR_DOMAINDNS names. Required for acme. First name is the default public host. Example: packages.taur.weirdbrains.com.
TAUR_BASE_URLLinks in mail and clone URLs. Unset: derived from the domain or the listen address.
TAUR_SSH_BINDEmbedded SSH. Unset means SSH is off. SSH is not the HTTPS certificate.
TAUR_GRPC_BINDgRPC. Plaintext HTTP/2 when TLS is off. The same certificate as HTTPS when TLS is acme.
TAUR_SMTP_URLMail. Unset writes files under outbox/.
TAUR_ADMINSUser names granted site admin at startup. Grant only.
TAUR_RPC_RATE_LIMITRPC calls per client per window. Default 300. 0 disables this class.

Full table: repository docs/configuration.md and docs/tls.md.

Automatic HTTPS

taur serve --tls acme --bind 0.0.0.0:443 \
  --domain packages.taur.weirdbrains.com \
  --acme-contact 'mailto:you@example.com' \
  --acme-accept-terms yes \
  --acme-http-bind 0.0.0.0:80

--acme-accept-terms must be the word yes after you read the CA agreement. There is no default contact. --acme-staging uses Let's Encrypt staging; those certificates are not publicly trusted. The CA must reach TCP port 80 for each domain. Until the first certificate exists, port 443 is not opened, and a failed renewal keeps the last good certificate. TAUR_TLS=off stays plaintext for local use or a proxy in front.

systemd

Service files live in the application repository on main (packaging/systemd/ and packaging/taur.env.example). Point EnvironmentFile= at a copy of that example. TAUR_BASE_URL should be https://packages.taur.weirdbrains.com. The process should be the only writer of TAUR_HOME.

Backup

Stop the server or use SQLite's online backup, then copy TAUR_HOME: taur.db, repos/ (including repos/.deleted/), ssh_host_ed25519_key, and acme/ if you use automatic HTTPS (it holds the account key). Restoring that directory onto the same version of the binary brings the instance back.

Upgrade

Build the new binary, stop the service, replace the binary, start it. The database applies small ALTER TABLE steps on open. Take the backup first. There is no separate migration command.
