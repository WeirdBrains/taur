Install and build

TAUR is a Rust workspace. You need Rust 1.99 or newer (edition 2024) and git on PATH. SQLite and protoc are bundled.

From source

git clone https://github.com/WeirdBrains/taur
cd taur
cargo build --release
./target/release/taur --version
./target/release/taurctl --version

The binaries are taur (server and admin) and taurctl (HTTP client). They land in target/release/.

A temporary server

./target/release/taur --home /tmp/taur-dev import tests/fixtures/hello-taur
./target/release/taur --home /tmp/taur-dev serve --bind 127.0.0.1:8080

--home is the data directory. Use a temporary one until you mean to keep the database. The default is ~/.local/share/taur.

Checks before you ship a build

cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo build --release

Helper tests run when yay or paru is on PATH. Point at a binary with TAUR_YAY or TAUR_PARU. TAUR_REQUIRE_HELPERS=yay,paru fails the run when one is missing.
