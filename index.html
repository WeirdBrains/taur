Package server

An AUR-compatible server for your own packages.

TAUR speaks the AUR RPC, serves one git repository per package base, and gives you accounts, organizations, and a small web UI. yay and paru can search it with --aururl.

InstallGuides

This site is the project documentation. The server you run has its own package UI at the bind address.

Features

  • RPC v5

    Search, info, suggest, and the legacy /rpc query string yay and paru send.

  • Git

    Smart HTTP and SSH clone and push. One bare repo per package base, branch master.

  • Helpers

    yay and paru flags per command, so your real helper config stays put.

  • Accounts

    Register, verify email, reset a password, session tokens, SSH keys.

  • Organizations

    Owner, admin, and contributor roles. An org can own a package base.

  • Community

    Votes, flags, comments, notifications, and requests. Adoption follows aurweb's request step.

Quick start

git clone https://github.com/WeirdBrains/taur
cd taur
cargo build --release
./target/release/taur --home /tmp/taur-dev import tests/fixtures/hello-taur
./target/release/taur --home /tmp/taur-dev serve --bind 127.0.0.1:8080

The public package service is https://packages.taur.weirdbrains.com. This site does not serve RPC or git. Without --save:

yay --aururl https://packages.taur.weirdbrains.com --aurrpcurl 'https://packages.taur.weirdbrains.com/rpc?' -Ss hello

TAUR is not Arch Linux and this mark is not the Arch Linux logo. Hosting at taur.weirdbrains.com is the intended name; this tree does not configure DNS or TLS.
